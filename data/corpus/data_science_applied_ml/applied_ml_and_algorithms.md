# Applied Machine Learning & Data Science: Master Algorithms and Practical Workflows

# Chapter 1: The Bias-Variance Tradeoff and Model Diagnostics
Generalization error decomposes into three fundamental components: Bias, Variance, and Irreducible Error. High Bias (underfitting) occurs when a model is overly simplistic and cannot capture the underlying structure of the data, exhibiting high training and validation error. High Variance (overfitting) occurs when a model is overly sensitive to training noise, resulting in low training error but high validation error. Learning curves plot training and validation loss against sample size; a wide gap signals high variance (remedy: more data, regularization, feature pruning), whereas converging high losses signal high bias (remedy: higher model capacity, richer feature engineering).

# Chapter 2: Feature Engineering, Scaling, and Encoding
Raw data requires rigorous preprocessing before model training. Missing data imputation strategies include median/mode imputation, KNN imputation, and iterative MICE. Categorical variables require appropriate encoding: One-Hot Encoding for nominal low-cardinality features, Target/Mean Encoding with smoothing and cross-fold out-of-fold calculation to prevent target leakage, and Ordinal Encoding for ranked features. Continuous feature transformation includes StandardScaler (z-score normalization: $\frac{x-\mu}{\sigma}$), MinMaxScaler ($\frac{x-min}{max-min}$ for bounded bounds), and Power Transforms (Box-Cox, Yeo-Johnson) to stabilize variance and normalize skewed distributions.

# Chapter 3: Supervised Classification and Regression Algorithms
Linear Regression models continuous targets with ordinary least squares (OLS), minimizing $\sum (y_i - \hat{y}_i)^2$. When multicollinearity is present, Ridge and Lasso regression provide numeric stability. Logistic Regression outputs calibrated probability estimates via the logit link function. K-Nearest Neighbors (KNN) is an instance-based lazy learner sensitive to distance metrics (Euclidean, Manhattan, Cosine) and curse of dimensionality. Decision Trees provide interpretable hierarchical rule systems. Naive Bayes classifies high-dimensional text data efficiently.

# Chapter 4: Ensemble Learning: Bagging, Random Forests, and Gradient Boosting
Ensemble methods combine multiple base learners to achieve superior predictive accuracy. Bagging (Bootstrap Aggregating) trains models in parallel on bootstrap samples with replacement, primarily reducing variance. Random Forests enhance bagging by selecting a random subset of $m \approx \sqrt{p}$ features at each split, decorrelating the constituent trees. Boosting trains models sequentially, where each new estimator corrects the residual errors of preceding models. Gradient Boosted Decision Trees (GBDT), XGBoost, LightGBM, and CatBoost optimize an arbitrary differentiable loss function via gradient descent in function space, utilizing second-order Taylor approximations and histogram-based binning.

# Chapter 5: Evaluation Metrics and Imbalanced Data Strategies
Accuracy is deceptive on imbalanced datasets. Precision measures positive predictive value: $\frac{TP}{TP+FP}$. Recall (Sensitivity) measures hit rate: $\frac{TP}{TP+FN}$. The $F_\beta$ score balances precision and recall: $F_1 = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$. The Receiver Operating Characteristic (ROC) curve plots True Positive Rate against False Positive Rate across classification thresholds; ROC-AUC measures ranking discrimination. Precision-Recall AUC (PR-AUC) is preferred when the positive class is rare. Imbalance mitigation techniques include SMOTE (Synthetic Minority Over-sampling Technique), focal loss, cost-sensitive class weighting, and threshold tuning.

# Chapter 6: Cross-Validation and Data Leakage Prevention
Data leakage occurs when information from outside the training dataset is inadvertently used to create the model, producing artificially optimistic validation scores. All feature transformations, imputers, scalers, and target encoders must be fit solely on training folds inside a pipeline. K-Fold Cross-Validation splits data into $K$ partitions. Stratified K-Fold preserves class distributions in classification tasks. Time-Series Split (Walk-Forward Validation) enforces strict temporal ordering, ensuring future data never informs past predictions. Group K-Fold ensures samples from the same entity/customer do not leak across train and validation splits.

# Chapter 7: Unsupervised Learning and Dimensionality Reduction
Unsupervised techniques uncover latent patterns without explicit labels. K-Means clustering partitions $N$ observations into $K$ clusters by minimizing within-cluster sum of squares (inertia); optimal $K$ is selected via the Elbow method or Silhouette Coefficient. Hierarchical Agglomerative Clustering builds bottom-up dendrograms with linkage criteria (Ward, Complete, Single). DBSCAN discovers clusters of arbitrary shape based on spatial density ($\epsilon$ radius and MinPts). Principal Component Analysis (PCA) performs orthogonal linear transformation to maximize variance along orthogonal eigenvectors derived from the data covariance matrix. t-SNE and UMAP provide non-linear dimensionality reduction for high-dimensional manifold visualization.
